# CodeAlpha Stock Portfolio Tracker

A simple Python-based Stock Portfolio Tracker developed as part of the **CodeAlpha Python Programming Internship**.

## 📌 Project Description

The Stock Portfolio Tracker allows users to enter stock names and quantities and calculates the total investment value using predefined stock prices.

The program also saves the final portfolio result in a text file.

## 🚀 Features

- Display predefined stock prices
- Accept stock name from the user
- Accept quantity of shares
- Calculate investment for each stock
- Calculate total investment
- Validate unavailable stock names
- Save the final result to a text file

## 🛠️ Technologies Used

- Python
- Dictionary
- Loops
- Conditional statements
- User input
- File handling
- Basic arithmetic
